# Death Counter Popup

*- More like Run Counter Popup, but I can't change the name now -*

A simple mod to add a text popup when you die, showing how many times you got that run (including runs from 0 and to 100).  
The percentage can be inaccurate if the level has different end points (like end trigger).

The data used in popup will be per level (daily/weekly, gauntlet, editor/copy, saved online levels are separated),
and will use data from Death Tracker if it's enabled (aggregate linked levels data).
You can also use the link levels feature from this mod using the UI found in the settings,
or if enabled, in the level info screens & pause menu.
